# Requirements: Notion inbox: capture from phone into the vault inbox

> Part of [index](index.md) · Define

## Requirements

EARS syntax. Each requirement has one acceptance criterion in Given/When/Then form. IDs are never reused; a dropped requirement is struck through, not deleted. A Won't meaning "never" is struck through with its reason; a Won't meaning "later" moves to the Deferred table below.

- **"Capture source"** means the external service the operator captures into from their phone. This session supports one: Notion.
- **"Source inbox"** means the database in the capture source that setup creates, with one row per capture.
- **"Instructions row"** means the one example row setup adds to the source inbox, explaining how to capture.
- **"Source item"** means a row in the source inbox, other than the instructions row.
- **"Status"** means a source item's status property: `New`, `Ingested` or `Failed`. A row whose status is empty counts as `New`.
- **"Reason"** means a source item's text property that explains a `Failed` status.
- **"Connector"** means what this session adds: the setup command and the pull run.
- **"Setup"** means one invocation of the connector's setup command.
- **"Pull run"** means one invocation of the connector's scheduled entrypoint. It pulls source items into the vault and ingests them.
- **"Connector config"** means the local file that holds the API key and the source inbox's ID. It's excluded from version control and lies outside the ingester agent's read scope.
- **"Ingester", "capture folder", "capture item", "placement target", "ask", "held" and "ingested"** have the meanings given in the ADR-0006 ingester's requirements (session `2026-09-28-inbox-resource-ingestion`, REQ-001 to REQ-042), and the ingester behaves as those requirements say.
- **"Pulled"** describes a source item that has been written to the vault as a capture item.
- **"Pull failure"** means a source item that couldn't be read, converted or written to the capture folder.
- **"Stopped"** describes a source item that has had a pull failure on 3 consecutive pull runs and has had an ask raised for it (REQ-018).
- **"Eligible source item"** means a source item that hasn't been pulled and isn't stopped, and whose status is `New`, or `Failed` because of a pull failure.
- **"Ledger"** means the connector's local, gitignored record of runs and item outcomes.
