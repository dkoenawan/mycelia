# 2027 goals

## Main goal: Run a marathon under 3:30

### Pillar: Endurance

Areas: [[health]]

- Run four times a week
- Build the long run to 32 km by September
- Keep easy runs at conversational pace
- One tempo run a week
- Run a half marathon in the spring
- Log every run
- Increase weekly distance by no more than 10%
- Take a lighter week every fourth week

### Pillar: Strength

Areas: [[health]]

- Two gym sessions a week
- Single-leg work in every session
- Core work three times a week

### Pillar: Recovery

Areas: [[health]], [[recreation]]

- Sleep eight hours on training nights
- A rest day after every long run

### Pillar: Nutrition

Areas: [[health]], [[finances]]

- Plan meals for the week on Sundays
- Practise race-day fuelling on long runs

### Pillar: Race planning

Areas: [[recreation]]

- Enter the autumn marathon by March
- Book travel and a place to stay

### Pillar: Mindset

Areas: [[personal-growth]]

- Visualise the race once a week in the last month

### Pillar: Gear

Areas: [[finances]]

- Replace running shoes every 700 km

### Pillar: Support

Areas: [[relationships]], [[home-environment]]

- Agree a training schedule with the household
- Find a running partner for long runs
