# daily

One `YYYY-MM-DD.md` note per day, written by agents via `append_daily` in
`scripts/lib/common.sh`.

This is where the estate reports what it did. Once the Layer 3 digest exists, this becomes
the single thing the operator reads to know the state of everything.
