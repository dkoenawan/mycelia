# 30-resources

PARA: **Resources**. Reference that applies across projects.

The highest-value contents are captured corrections — a standard the operator had to explain once,
written down so it never has to be explained again. These carry `type: feedback` with
**Why:** and **How to apply:** lines.

Resource notes also arrive from `00-inbox/capture/` through the ingester (`task ingest-inbox`):
each capture becomes a `type: resource` note with a summary and key takeaways, linked to the
areas and projects it serves, with the original kept in `40-archive/capture/`.
